# Windows Server Administration

## Introduction

This project documents my hands-on experience administering Windows Server 2019 in an enterprise environment.

As a Junior System Administrator, I am responsible for supporting users, maintaining server operations, managing Active Directory services, monitoring backups, configuring DNS and DHCP, troubleshooting issues, and ensuring the availability of critical IT services.

This repository demonstrates the practical administration tasks, technologies, and troubleshooting activities performed in a production environment.
